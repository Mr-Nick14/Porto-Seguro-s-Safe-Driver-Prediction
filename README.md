# HW2. Porto Seguro Safe Driver Prediction

Мы решаем задачу бинарной классификации и прогнозируем вероятность страхового случая. Качество оцениваем с помощью Normalized Gini.

Лучший локальный результат получили в четвертой попытке с LightGBM. Gini составил `0.29229`. Итоговый прогноз лежит в `submission_lgbm_simple.csv` и `submission.csv`.

Все эксперименты, графики и выводы находятся в `research.ipynb`.
